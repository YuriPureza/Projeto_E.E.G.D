# Maquinas-de-pacientes-para-clinica-psiquitrica

Projeto para renovar a infra dos computadores dos pacientes.

O objetivo do projeto é aprender a como configurar um computador com bloqueios e licenças para que pacientes que estão internados em uma clínica psiquiátrica não possam acessar sites proibidos ou baixar aplicativos. Principalmente bloqueando o acesso a funções do computador onde poderiam ter quebras de segurança, pois existem paciente sem experiencia com computador, porém, sempre pode ter a exceção de alguém que trabalha na área de TI.


Será tudo feito e documentado aqui, para que além de fim de estudo, seja feito para demonstrar experiência e vontade de aprender coisas novas.

Esse também é o inicio de tentar dar uma melhorada na minha carreira pra futuramente eu conseguir chegar ao cargo de governança de TI e quem sabe no de CTO.
